# 데이터와 모델 설명

## 데이터

- **이름**: UCI Bike Sharing Dataset — hour.csv
- **출처**: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- **라이선스**: CC BY 4.0 (재배포 가능, 출처 표기 필요)
- **기간**: 2011~2012년, Washington D.C. Capital Bikeshare
- **크기**: 17,379행 17열 (결측치·이상값 없음, 제거 0행)
- **SHA256**: `e03de4ee4ef4dc376ac6e04bf829673c6269e8eba5c60fa121640fa2f829504f`

## 입력 피처

| 피처 | 설명 | 타입 | 범위 |
|---|---|---|---|
| season | 계절 (1=봄, 2=여름, 3=가을, 4=겨울) | int | 1~4 |
| mnth | 월 | int | 1~12 |
| hr | 시간 | int | 0~23 |
| holiday | 공휴일 여부 | int | 0, 1 |
| weekday | 요일 (0=일요일) | int | 0~6 |
| workingday | 근무일 여부 | int | 0, 1 |
| weathersit | 날씨 상태 (1=맑음 ~ 4=폭우) | int | 1~4 |
| temp | 정규화된 기온 = 실제 기온(°C) ÷ 41 | float | 0~1 |
| atemp | 정규화된 체감 기온 = 체감 기온(°C) ÷ 50 | float | 0~1 |
| hum | 정규화된 습도 = 습도(%) ÷ 100 | float | 0~1 |
| windspeed | 정규화된 풍속 = 풍속(km/h) ÷ 67 | float | 0~1 |

## 제외 피처 (누수 방지)

| 피처 | 제외 이유 |
|---|---|
| casual | casual + registered = cnt (정답 누수) |
| registered | 위와 동일 |
| instant | 단순 행 번호, 의미 없음 |
| dteday | 날짜 문자열, hr/mnth 등에 이미 포함 |
| yr | 실험 결과: 평가 데이터에 yr=1만 존재해 학습 범위 밖 → 제외 |

## 출력

- **타겟**: `cnt` — 해당 시간의 실제 대여 대수 (대/시간)

## 데이터 분할 기준

시간 순서 기반 분할 (무작위 분할 금지 — 미래 데이터 누수 방지):

| 분할 | 기준 | 행 수 |
|---|---|---|
| 학습 | yr=0 (2011년) | 8,645행 |
| 평가 | yr=1 (2012년) | 8,734행 |

## 모델

- **종류**: `sklearn.ensemble.RandomForestRegressor`
- **하이퍼파라미터**: `n_estimators=200`, `random_state=42`, `n_jobs=-1`
- **버전(SHA256[:12])**: `8b6cf2669bbe`

## 평가 결과

| | MAE (대/시간) | RMSE (대/시간) |
|---|---|---|
| **RandomForest 모델** | **88.78** | **125.22** |
| 베이스라인 (hr별 평균) | 118.16 | 174.27 |
| 베이스라인 (전체 평균) | 168.25 | 227.81 |

모델이 hr별 베이스라인 대비 MAE 25% 개선.
