# 오답 분석 (오차 최대 1건)

- **인덱스**: 1977
- **입력**:
  ```
  season: 2        → 여름
  mnth: 3          → 3월
  hr: 17           → 오후 5시 (퇴근 러시아워)
  holiday: 0       → 공휴일 아님
  weekday: 5       → 토요일
  workingday: 1    → 근무일
  weathersit: 2    → 흐림/안개
  temp: 0.72       → 실제 기온 약 29.5°C (0.72 × 41)
  atemp: 0.6515    → 체감 기온 약 32.6°C (0.6515 × 50)
  hum: 0.42        → 습도 42%
  windspeed: 0.1642 → 풍속 약 11 km/h (0.1642 × 67)
  ```
- **정답(cnt)**: 957 대/시간
- **예측값**: 348.1 대/시간
- **오차**: 608.9 대/시간 (실제의 약 64% 과소 예측)

## 원인 추정

**1. 연도별 이용자 증가 추세 미반영 (주요 원인)**
- 모델은 2011년(yr=0) 데이터로 학습했고, `yr` 피처를 제외했다.
- Capital Bikeshare는 2012년에 스테이션과 자전거 수를 대폭 확충했다.
- 같은 조건(시간·날씨)이라도 2012년 실제 수요가 2011년보다 구조적으로 높다.
- 모델이 학습한 2011년의 최대 cnt 범위를 2012년 실수요가 초과했다.

**2. 퇴근 러시아워 + 쾌적한 날씨 조합**
- hr=17(오후 5시)은 하루 중 대여량이 가장 많은 시간대다.
- 기온 29.5°C, 습도 42%는 자전거 이용에 매우 쾌적한 조건이다.
- 두 요인이 겹쳐 실제 수요가 비정상적으로 높았을 가능성이 있다.

**3. 모델의 구조적 한계**
- RandomForest는 학습 데이터 범위 밖의 값을 외삽(extrapolation)하지 못한다.
- 학습 데이터(2011년)의 cnt 최댓값보다 높은 수요는 과소 예측하는 경향이 있다.
